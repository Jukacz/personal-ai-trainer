# AI Personal Trainer

AI Personal Trainer to aplikacja webowa, która generuje spersonalizowane plany treningowe na podstawie celu użytkownika, poziomu zaawansowania i danych profilu.

System łączy backend oparty o agenty AI z frontendem do planowania i śledzenia treningów. Użytkownik może tworzyć plan, przeglądać dni treningowe, zarządzać ćwiczeniami i monitorować postępy.

## Tech Stack

### Backend
- Python 3.13
- FastAPI
- LangChain
- MongoDB
- Google Gemini
- MuscleWiki API
- JWT (autoryzacja)

### Frontend
- Next.js 15
- React
- TypeScript
- Tailwind CSS 4
- shadcn/ui
- React Hook Form + Zod
- React Query
- Axios
- pnpm
